# 🔗 QuickLink - URL Shortener

A simple and responsive URL Shortener built using HTML5, CSS3,
JavaScript and the Fetch API.

## 🚀 Features

- Enter a long URL
- Validate URL before submission
- Shorten URLs using a public API
- Display shortened URL
- Copy shortened URL to clipboard
- Open shortened URL
- Store recent links in LocalStorage
- Display URL history
- Clear URL history
- Responsive design
- API error handling

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- LocalStorage
- is.gd Public API

## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a valid URL.
5. Click "Shorten URL".
6. Copy or open the generated short URL.

## 🔗 API

This project uses the public is.gd URL shortening API.

API endpoint:

https://is.gd/create.php

## 💾 LocalStorage

The application stores the latest 10 shortened URLs in the
browser's LocalStorage.

The stored information includes:

- Original URL
- Shortened URL
- Date and time
